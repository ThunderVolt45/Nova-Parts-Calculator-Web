# 라이선스 고지 관리

`REFERENCE_PROJECTS.txt`는 웹 구현의 기준이 된 MIT 프로젝트의 원 저작권
고지와 기여자 귀속을 보존합니다.

`npm run licenses:generate`는 이 파일과 설치된 npm 패키지의 라이선스 원문을
합쳐 다음 공개 파일을 생성합니다.

- `public/LICENSE.txt`: 현재 웹 프로젝트의 MIT 라이선스
- `public/THIRD_PARTY_LICENSES.txt`: 기준 프로젝트와 npm 제3자 라이선스

생성 파일은 프로덕션 빌드 전에 자동으로 갱신됩니다. 패키지를 추가하거나
버전을 변경하면 생성 명령을 실행하고 두 공개 파일의 변경도 함께 커밋합니다.
라이선스 파일을 찾을 수 없는 배포 의존성이 있으면 생성 명령은 실패합니다.
일부 npm 배포본이 선언한 라이선스 파일을 포함하지 않은 경우에는 생성
스크립트의 명시적 패키지별 고지 또는 표준 SPDX 원문을 사용합니다. 새 예외를
추가할 때는 공식 저장소와 패키지 메타데이터에서 저작권자와 라이선스를 먼저
확인하며, 같은 SPDX 식별자를 가진 다른 프로젝트의 저작권 문구를 대신
사용하지 않습니다.
