# 부품 카탈로그 스키마

## 목적

기준 Python 계산기의 JSON은 계산 결과의 원천 데이터로 보존하되, 웹 앱은
원본 파일 형식을 직접 소비하지 않습니다. 로딩 시 원본 스키마를 검증하고
정규화한 뒤, 계산기·덱·3D 매핑이 함께 사용하는 도메인 카탈로그를 만듭니다.

## 데이터 경계

원본 형식에서 확인된 특징은 다음과 같습니다.

- 다리 41개, 몸통 59개, 무기 65개, 액세서리 78개
- 각 부품 종류 안에서 `ID`는 중복되지 않으며 현재 데이터는 0부터 연속적임
- 몸통과 무기의 `Type`은 `0` 없음, `1` 탑, `2` 팔, `3` 어깨를 의미함
- 공격 대상 필드는 파일에 따라 JSON boolean 또는 `"TRUE"`/`"FALSE"` 문자열임
- 서브코어 13개는 객체 배열이 아니라 동일 길이의 병렬 배열로 저장됨
- 사지타리움은 무기 슬롯에서만 사거리와 설명이 달라짐
- 다리의 `Weight`는 부품 무게가 아니라 유닛의 하중 한도임
- 음수 능력치는 유효함. 예를 들어 액세서리 체력, 부품 방어력, 사거리,
  리젠 및 연사 보정에 음수가 존재함

## 정규화 모델

- 필드명은 camelCase를 사용합니다.
- 부품 종류는 `kind` 판별 필드로 구분합니다.
- 다리의 `Weight`는 `loadCapacity`, 나머지 부품은 `weight`로 분리합니다.
- 몸통·무기 형식은 `none | tower | arm | shoulder`로 변환합니다.
- 숫자 기반 특수 효과는 계산 의미를 드러내는 문자열 열거형으로 변환합니다.
- 공통 능력치는 `stats`에 모으며 수치 단위를 필드명에 표시합니다.
- 서브코어는 객체 배열로 변환하고 `leg`, `body`, `weapon` 슬롯별 효과를
  완전히 펼쳐 저장합니다. 계산기는 사지타리움 예외를 별도로 알 필요가 없습니다.
- 카탈로그와 덱은 배열 위치가 아닌 종류별 `id`로 부품을 참조합니다.

## 버전 정책

`catalogVersion`은 `<스키마 버전>-<최종 source JSON의 SHA-256 앞 12자리>`
형식을 사용합니다. JSON은 `JSON.stringify(snapshot.source)`로 직렬화합니다.
이전에는 기준 저장소 커밋 앞 12자리를 사용했지만, 웹 전용 수치 보정과
밸런스 패치도 버전에 반영하도록 변경했습니다. 정규화 의미가 바뀌면
스키마 버전을 올리고, 부품 데이터가 바뀌면 해시 부분이 자동으로 바뀝니다.
`sourceRevision`에는 기준 Python 저장소의 전체 커밋 해시를 보존합니다.
덱 내보내기와 마이그레이션 판단에 같은 값을 사용합니다.

`npm run catalog:import`는 형제 디렉터리의 기준 저장소를 읽어
`catalog.snapshot.json`을 다시 생성합니다. 기준 저장소의 `JSON` 디렉터리에
커밋되지 않은 변경이 있으면 리비전과 데이터가 어긋나지 않도록 중단합니다.
다른 위치의 기준 저장소를 사용하려면 경로를 첫 번째 인자로 전달합니다.

웹 전용 보정과 공식 패치는 `src/data/catalog/catalog.overrides.json`에서
종류·ID·이름별로 관리하고 가져오기 시 적용합니다. 골든 데이터 생성기도
같은 보정을 Python 모듈의 메모리 데이터에 적용하며 기준 저장소는 수정하지
않습니다. 수치 변경 후 카탈로그, 세 종류의 계산 골든 데이터, GX 매핑을
차례로 재생성합니다.

2026-09-16 패치는 [공식 점검 공지](https://nova1492.kr/notice/1710973)를
기준으로 다리 5개, 몸통 9개, 무기 12개, 액세서리 9개의 총 59개 수치를
반영했습니다. 공지의 `스쿼미시`, `데미시즈n`, `타워링 2`는 각각 기존
`스쿼미쉬`, `데미시즈N`, `타워링II`에 대응하며 부품 이름과 ID는 유지합니다.

원본 호환 스키마와 정규화 함수는 `src/data/catalog/legacyCatalog.ts`, 앱 내부
도메인 스키마는 `src/domain/catalog/schema.ts`, 검증된 앱 카탈로그 진입점은
`src/data/catalog/catalog.ts`에 둡니다.
