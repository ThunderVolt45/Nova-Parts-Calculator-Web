# 기본 계산 엔진

## 범위

기본 계산 엔진은 기준 Python 계산기의 `utils.py` 강화 공식과 `assemble.py`
조립 능력치 계산을 순수 TypeScript로 이식합니다. 입력은 카탈로그 배열 위치가
아닌 부품 및 서브코어 ID를 사용하며, 카탈로그 조회 인터페이스를 주입받습니다.

현재 출력은 다음 값을 포함합니다.

- 사용 무게와 다리 하중
- 와트, 체력, 공격력
- 리젠, 속도, 연사, 사거리, 최소 사거리, 범위, 시야
- 체력 비례 피해, 방어 무시, 방어력
- 무기의 지상 및 공중 공격 가능 여부

최종 계산 엔진은 기본 결과를 입력으로 받아 다음 보정을 별도로 적용합니다.

- 몸통 저체력 효과와 무기 조건부 효과
- 일반 및 강화 타워링
- 공격·방어 기본, 팀 듀얼, 지상/공중 계열, 데스페라, 데블스피릿, 모랄,
  세크리파이, 팀 공격 및 팀 방어 스킬
- 데스매치와 스퀘어 공격·속도·연사 진형
- 최종 공격력 기반 체력 흡수량과 최종 체력 기반 리젠량

`calculateAssemblyStats`는 같은 입력에서 `{ base, final }`을 반환하여 기본
능력치와 최종 능력치를 섞지 않습니다.

## Python 동작 보존

- 강화 수치별 정수 모드 `int()`는 `Math.trunc()`로 같은 위치에서 적용합니다.
- 부품별 강화 값을 더한 뒤 체력 및 공격 퍼센트 배율을 적용합니다.
- 정수 모드는 최종 체력 및 공격력에도 다시 절삭을 적용합니다.
- 실수 모드는 Python과 같이 최종 와트, 체력, 공격력을 소수점 넷째 자리로
  반올림합니다.
- 속도 120 상한, 시야 30 상한, 연사 50 하한과 음수 와트·체력·공격력·방어력
  방지 규칙을 같은 순서로 적용합니다.
- 액세서리 랜덤 옵션은 `HasRandomOption`이 참인 액세서리에만 적용합니다.
- 사지타리움 무기 슬롯은 정규화 카탈로그의 슬롯별 효과를 사용합니다.

## 동등성 검사

`npm run calculation:golden`은 기준 Python 계산기를 실행하여 골든 fixture를
생성합니다. 생성기는 기준 저장소 리비전이 이식된 카탈로그 리비전과 다르면
중단합니다.

현재 fixture에는 다음 526개 조합이 들어 있습니다.

- 정수 모드 대표 및 경계 조합 7개
- 실수 모드 대표 및 경계 조합 7개
- 고정 시드 `1492` 정수 모드 무작위 조합 256개
- 고정 시드 `1492` 실수 모드 무작위 조합 256개

Vitest는 모든 조합의 전체 기본 계산 결과를 TypeScript 엔진과 비교합니다.
최종 능력치는 실제 PyQt `WindowClass.Assemble()`을 오프스크린으로 실행해
대표·경계 조합 18개와 고정 시드 무작위 조합 256개, 총 274개 결과를 별도
fixture로 생성하고 전수 비교합니다.

기준 GUI의 실수 모드는 기본 결과 문자열에 소수점이 포함되면 최종 계산의
`int()` 문자열 변환에서 예외가 발생합니다. 웹 엔진은 수치에 Python
`int()`와 같은 절삭을 직접 적용하여 실수 모드에서도 최종 계산이 중단되지
않도록 하며, 이 경계는 별도 단위 테스트로 고정합니다.

조립 유효성 검사도 같은 fixture 체계로 검증합니다.

## 조립 유효성

유효성 검사는 계산 결과와 분리된 `validateAssembly` 순수 함수로 제공합니다.
다음 규칙을 각각 오류 코드로 반환합니다.

- 다리, 몸통, 무기 누락
- 몸통과 무기 형식 불일치
- 다리 하중 초과
- N 부품 두 개 이상 선택
- 아포칼립스에 무게 30 미만 몸통 사용
- 아포칼립스와 타워링 액세서리 동시 사용

Python 화면은 대표 상태 하나만 표시하지만 여러 부품을 동시에 붉게 표시할
수 있습니다. 웹 결과는 모든 `issues`, Python과 같은 우선순위의 `status`,
`invalidPartSlots`, `weightInvalid`를 함께 반환하여 정보 손실 없이 같은 화면을
구현할 수 있습니다.

실제 PyQt 계산기에서 규칙별·복합 오류 15개와 고정 시드 무작위 조합 512개,
총 527개의 상태 및 오류 표시 대상을 생성해 TypeScript 결과와 전수 비교합니다.
