# Nova Assembly 사용자 가이드

Nova Assembly는 노바 1492의 부품 조합과 능력치를 계산하는 비공식 팬 제작
도구입니다. 계산기와 덱은 데스크톱·모바일에서 사용할 수 있고, 로컬 게임
리소스를 이용한 3D 미리보기는 PC에서만 사용할 수 있습니다.

## 부품 조립과 계산

1. `부품 조립`에서 다리, 몸통, 무기, 액세서리를 선택합니다.
2. 다리·몸통·무기의 와트, 체력, 공격 강화와 서브코어를 설정합니다.
3. 액세서리의 랜덤 체력, 공격, 방어 옵션을 입력합니다.
4. 필요하면 정수/실수 계산 모드와 스킬·상태·진형 등 시뮬레이션 조건을
   설정합니다.
5. 결과 패널에서 조립 유효성, 기본 능력치와 최종 능력치를 확인합니다.

입력을 바꾸면 결과가 바로 갱신됩니다. 몸통과 무기의 타입 불일치, 하중 초과,
필수 부품 누락 같은 문제가 있으면 `조립 불가` 사유가 함께 표시됩니다.
`초기화`는 현재 조립 입력을 기본 상태로 되돌립니다.

## 덱 사용

- 덱 하나에는 10개의 유닛 슬롯이 있으며 빈 슬롯도 허용됩니다.
- `새 덱`, `덱 복제`, `삭제`로 여러 덱을 관리하고 이름 입력란에서 덱 이름을
  바꿀 수 있습니다.
- 슬롯을 선택하고 유닛 이름을 입력한 뒤 `유닛 등록`을 누르면 현재 조립을
  저장하거나 기존 슬롯을 교체합니다.
- 저장된 슬롯을 선택하면 해당 조립을 계산기로 불러옵니다. `유닛 복사`,
  `유닛 붙여넣기`, `슬롯 비우기`로 슬롯을 편집할 수 있습니다.

마지막으로 사용한 덱과 선택 슬롯은 브라우저에 복원됩니다. 스킬, 상태,
타워링, 데스매치, 진형 같은 전투 시뮬레이션 조건은 덱 유닛에 저장되지
않습니다.

## JSON 백업과 복원

`현재 유닛`, `현재 덱`, `전체 덱` 중 필요한 범위를 JSON으로 내보낼 수
있습니다. 가져올 때는 다음 방식 중 하나를 선택합니다.

- 유닛 JSON: 현재 선택 슬롯에 붙여넣거나 새 덱으로 가져옵니다.
- 덱/백업 JSON: 기존 덱과 병합하거나 모든 덱을 가져온 내용으로 교체합니다.

교체 가져오기는 기존 덱 전체를 바꾸므로 먼저 전체 덱 백업을 내보내는 것이
안전합니다. JSON에는 GX, XFI, 텍스처, 변환 GLB 같은 게임 리소스가 포함되지
않습니다. 형식이나 값이 올바르지 않으면 가져오기 전에 오류 또는 복구 경고가
표시됩니다.

## PC에서 3D 미리보기 사용

1. PC에서 3D 패널의 `common 폴더 선택`을 누릅니다.
2. Nova 1492 설치 폴더 아래의 `datan/common` 디렉터리를 선택하고 브라우저의
   읽기 승인을 확인합니다.
3. 파일 인덱싱과 GLB 변환이 끝나면 부품 썸네일과 조립 모델이 표시됩니다.
4. 회전, 확대/축소, 카메라 초기화와 `idle`, `move`, `attack` 재생 제어를
   사용할 수 있습니다.

선택한 원본 파일은 브라우저 안에서만 읽고 서버로 전송하지 않습니다. 변환된
GLB, 파서 메타데이터와 UI 스프라이트는 다음 방문을 빠르게 하기 위해
IndexedDB에 저장될 수 있습니다. 원본 게임 파일은 복제하거나 변경하지
않습니다.

브라우저나 운영체제에 따라 폴더 선택 화면과 권한 유지 방식이 다를 수
있습니다. 권한이 사라지거나 필요한 모델이 캐시에 없으면 `common` 폴더를
다시 선택합니다. 모바일에서는 계산기와 덱만 제공하며 3D 기능은 비활성화됩니다.

## 로컬 데이터와 문제 해결

- 3D 패널의 `리소스 캐시 > 전체 삭제`는 변환 모델과 UI 스프라이트 캐시만
  삭제하며 덱과 원본 게임 파일은 건드리지 않습니다.
- 덱을 포함한 모든 로컬 데이터를 지우려면 브라우저 설정에서 이 사이트의
  저장 데이터를 삭제합니다. 삭제 전에는 전체 덱 JSON 백업을 권장합니다.
- 모델이 표시되지 않으면 연결 결과의 누락·매핑 미해결 수치를 확인하고 올바른
  `datan/common` 폴더를 다시 선택합니다.
- 버그는 화면 상단의 `버그 신고`를 이용합니다. 공개 이슈에는 개인정보,
  로컬 설치 경로, GX·XFI·텍스처 등 게임 원본 파일을 첨부하지 않습니다.

서비스의 비제휴 관계, 로컬 저장, 호스팅 기술 로그와 권리 침해 신고 방법은
화면 상단의 `서비스 안내`에서 확인할 수 있습니다.
